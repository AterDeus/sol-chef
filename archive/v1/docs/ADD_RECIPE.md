# Как добавить рецепт

## Workflow (рекомендуется)

1. **Внешняя модель** — системный промпт из [RECIPE_AI_SYSTEM.md](RECIPE_AI_SYSTEM.md) (или короткая версия [RECIPE_AI_PROMPT.txt](RECIPE_AI_PROMPT.txt)).
2. Отправьте ссылку + заметки после просмотра видео / текст страницы.
3. Скопируйте ответ модели — блок ` ```JSON ` с объектом или массивом внутри (можно вставить целиком).
4. **Проверка** (опционально, до Cursor; валидатор снимает markdown-обёртку):

```bash
node scripts/validate-recipes.js --import draft.md
# или из буфера:
node scripts/validate-recipes.js --stdin < draft.md
```

5. **Cursor** — «Добавь этот рецепт на сайт sol-chef» (или «эти рецепты» для массива) + вставьте ответ.
6. `git push`.

### Ответ с ошибкой

Если модель вернула в блоке ` ```JSON `:

```JSON
{ "error": "Не удалось распознать источник..." }
```

— исправьте ссылку или приложите текст рецепта и повторите. **Не добавляйте** такой объект в базу рецептов — CI его отклонит.

## Быстрый путь (только Cursor)

```
Добавь рецепт в data/recipes/.

Метод: [духовка / сковорода / гриль / тушение / кастрюля]
Продукт: [птица / говядина / крупы / …]
Источник: [ссылка]
Заметки: [конспект]

Следуй data/schemas/recipe.schema.json
```

## Где лежат файлы

Рецепты разбиты по **методу готовки** (папка) и **типу основного продукта** (файл):

```
data/recipes/
  index.json              — список всех файлов (сайт грузит отсюда)
  duhovka/                — духовка / запекание
    ptitsa.json
    govyadina.json
  skovoroda/              — сковорода / обжарка
    govyadina.json
  grill/                  — гриль / мангал
    govyadina.json
  tushenie/               — тушение / долгое томление
    govyadina.json
    ptitsa.json
  kastryulya/             — кастрюля / варка на плите
    krupy.json
```

Каждый файл — **массив** объектов рецептов. Новый рецепт добавляется в подходящий файл; если файла ещё нет — создайте и пропишите путь в `index.json` → `files`.

| Метод (папка) | Когда использовать |
|---------------|-------------------|
| `duhovka` | Основное время в духовке (в т.ч. reverse sear) |
| `skovoroda` | Обжарка на сковороде |
| `grill` | Гриль, мангал, угли |
| `tushenie` | Долгое томление в кастрюле / казане |
| `kastryulya` | Варка круп, пасты, блюд «на плите» |

| Продукт (файл) | `category` в рецепте |
|----------------|----------------------|
| `ptitsa.json` | `птица` |
| `govyadina.json` | `говядина` |
| `krupy.json` | `крупы` |
| `pasta.json` | `паста` |
| `baranina.json` | `баранина` |
| `zavtrak.json` | `завтрак` |
| `desert.json` | `десерт` |
| `svinina.json` | `свинина` |
| `sousy.json` | `соусы` |
| `ryba.json` | `рыба` |
| … | см. список категорий ниже |

`id` рецепта должны быть **уникальны во всей базе**, не только в одном файле.

## Поля

| Поле | Обязательно | Описание |
|------|-------------|----------|
| id | да | Транслит русского title: `idealnyj-stejk-ribaj` |
| title | да | Название блюда |
| source_url | нет | Главная ссылка на видео/статью; если источника нет — опустите или оставьте пустым |
| summary | да | Краткий конспект (2–4 предложения) |
| tags | да | 2–5 тегов, без дублирования `category` |
| source_type | нет | `video` или `article` |
| source_name | нет | Канал / сайт |
| category | нет | См. список ниже |
| ingredients | нет | Структурированный список (см. ниже) |
| steps | нет | Шаги (строка или объект с таймером, см. ниже) |
| prep | нет | Напоминания заранее: разморозка, маринад, комнат. темп. |
| notes | нет | Нюансы, вторая ссылка, таймкоды |
| variations | нет | Вариации базового рецепта (см. ниже) |
| added | нет | YYYY-MM-DD |
| tried | нет | `true` — уже готовил сам (метка ✓ у названия на сайте). Ставится вручную, не через ИИ |

### Категории (`category`)

Допустимые значения (одно слово):

`птица`, `говядина`, `свинина`, `баранина`, `крупы`, `рис`, `гарнир`, `паста`, `суп`, `выпечка`, `десерт`, `соусы`, `завтрак`, `рыба`

## Ингредиенты (`ingredients`)

Массив объектов. На сайте собираются в читаемую строку; поля нужны для будущего пересчёта порций.

```json
"ingredients": [
  { "name": "сыр", "amount": 80, "unit": "г", "detail": "пармезан или пекорино романо (мелко натертый)", "scalable": true },
  { "name": "лук", "amount": 0.5, "unit": "шт", "detail": "репчатый, мелко нарезать", "scalable": true },
  { "name": "бульон", "amount": 700, "amount_max": 800, "unit": "мл", "detail": "куриный или овощной, горячий", "scalable": true },
  { "name": "соль", "detail": "по вкусу", "scalable": false }
]
```

| Поле | Обязательно | Описание |
|------|-------------|----------|
| name | да | Короткое название продукта |
| amount | нет | Количество (число; для «1/2 шт» → `0.5`) |
| amount_max | нет | Верхняя граница диапазона (`350–400 г` → `amount: 350`, `amount_max: 400`) |
| unit | нет | `г`, `кг`, `мл`, `л`, `шт`, `ч. л.`, `ст. л.`, `зубчик` и т.д. |
| detail | нет | Сорт, нарезка, «по вкусу», «для подачи», замены |
| scalable | нет | `true` — пересчитывать при смене порции; `false` — соль, перец, вода для варки, гарнир |
| scale_mode | нет | `linear` (по умолчанию), `gentle` — слабее (сода, разрыхлитель), `whole` — только целые шт (яйца) |

На странице рецепта блок **«У меня»** берёт первый масштабируемый ингредиент с весом/объёмом (или первый с `amount`) как базу. Остальные `scalable: true` пересчитываются пропорционально; `gentle` и `whole` — по правилам выше. Шаг кнопок ±: **50 г** при количестве &lt; 500 г, **250 г** при ≥ 500 г (аналогично для мл). Таймеры не меняются.

## Подготовка заранее (`prep`)

Массив напоминаний до начала готовки. Показываются на странице рецепта и в режиме готовки с push-уведомлением.

```json
"prep": [
  { "text": "Разморозить лопатку в холодильнике", "before_hours": 12, "type": "thaw" },
  { "text": "Достать масло — комнатная температура", "before_min": 60, "type": "room_temp" },
  { "text": "Замариновать курицу", "before_hours": 24, "type": "marinate" }
]
```

| Поле | Обязательно | Описание |
|------|-------------|----------|
| text | да | Что сделать |
| before_min | * | За сколько минут до старта (одно из before_min / before_hours) |
| before_hours | * | За сколько часов до старта |
| type | нет | `thaw`, `fridge`, `room_temp`, `marinate`, `soak`, `custom` |

## Вариации (`variations`)

Базовый рецепт в `ingredients` / `steps` — общая техника. Отличия вариантов — в сворачиваемом блоке «Вариации» на странице (режим готовки их не переключает).

```json
"variations": [
  {
    "title": "С грибами",
    "text": "200 г шампиньонов обжарить отдельно. На шаге с добавлением бульона — вмешать грибы вместе с пармезаном."
  },
  {
    "title": "С морепродуктами",
    "text": "Креветки и мидии добавить за 3–4 мин до конца, не кипятить — иначе резина."
  }
]
```

| Поле | Обязательно | Описание |
|------|-------------|----------|
| title | да | Название вариации |
| text | да | Чем отличается приготовление. Plain text или ограниченный HTML |

### HTML в `variations[].text`

Допустимые теги (без атрибутов): `p`, `br`, `strong`, `b`, `em`, `i`, `ul`, `ol`, `li`.

Запрещены: ссылки, картинки, `script`, любые `on*`‑атрибуты.

```json
{
  "title": "С грибами",
  "text": "<p>200 г шампиньонов обжарить отдельно.</p><ul><li><strong>Когда:</strong> за 5 мин до конца</li><li>Не в общем сотейнике — отдадут воду</li></ul>"
}
```

На сайте HTML проходит санитизацию — лишние теги отрежутся.

## Шаги с таймером (`steps`)

Шаг — строка или объект:

```json
"steps": [
  "Разогреть духовку до 200°C.",
  { "text": "Запекать до 62°C в бедре", "timer_min": 50, "timer_label": "Запекание", "timer_note": "Мелкая птица 45–50 мин, крупная дольше — снимайте по термометру, не по таймеру" },
  { "text": "Отдых перед нарезкой", "timer_min": 15, "timer_label": "Отдых", "timer_note": "Фиксированный отдых; не зависит от размера тушки" }
]
```

| Поле | Описание |
|------|----------|
| text | Текст шага |
| timer_min | Минуты таймера (ориентир по умолчанию) |
| timer_sec | Секунды (дополнительно к timer_min) |
| timer_label | Короткая подпись («Запекание», «Отдых») |
| timer_note | Оговорка: для какой порции/веса, когда ориентир неточен; в cook mode время можно подстроить вручную |

**Таймеры не масштабируются** вместе с ингредиентами. `timer_min` — отправная точка; критерий готовности — в `text` шага (температура, мягкость). `timer_note` поясняет, когда время может отличаться. В режиме готовки пользователь меняет длительность кнопками ± перед стартом.

## Несколько рецептов из одного источника

Модель может вернуть массив внутри блока:

```JSON
[
  { "id": "domashnij-majonez-blender", ... },
  { "id": "klassicheskij-sous-tartar", ... }
]
```

Передайте ответ целиком в Cursor. Каждый объект проверяется отдельно; `id` должны быть уникальны внутри массива и не совпадать с уже существующими в базе.

## После добавления

```bash
node scripts/validate-recipes.js
python -m http.server 3456
```

Проверить: вкладка «Рецепты», `recipe.html?id=...`
