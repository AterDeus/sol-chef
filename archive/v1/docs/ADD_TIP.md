# Как добавить совет

Советы хранятся в `data/tips.json`. Каждый блок — секция с `id`, `title` и массивом `items`.

## Промпт

```
Добавь совет в data/tips.json.

Текст: [формулировка совета]
Секция: [id и название, например "03 — Сковорода, обжаривание, тепло"]

Правила:
- Следуй data/schemas/tip.schema.json
- Не дублируй существующие советы
- id секции — две цифры ("01" … "09")
- Если нужна новая секция — добавь с следующим id
```

## Пример

```
Добавь совет в data/tips.json.

Текст: Переворачивайте стейк tongs, не вилкой — не прокалывайте мясо.
Секция: 03 — Сковорода, обжаривание, тепло
```

## Проверка

```bash
node scripts/validate-tips.js
```
