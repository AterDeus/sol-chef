# Как добавить рецепт

## Workflow (рекомендуется)

1. **Внешняя модель** — системный промпт из [RECIPE_AI_SYSTEM.md](RECIPE_AI_SYSTEM.md) (или короткая версия [RECIPE_AI_PROMPT.txt](RECIPE_AI_PROMPT.txt)).
2. Отправьте ссылку + заметки после просмотра видео / текст страницы.
3. Скопируйте ответ модели — блок ` ```JSON ` с объектом или массивом внутри (можно вставить целиком).
4. **Проверка** (опционально, до Cursor; валидатор снимает markdown-обёртку):

```bash
node scripts/validate-recipes.js --import draft.md
# или из буфера:
node scripts/validate-recipes.js --stdin < draft.md
```

5. **Cursor** — «Добавь этот рецепт на сайт sol-chef» (или «эти рецепты» для массива) + вставьте ответ.
6. `git push`.

### Ответ с ошибкой

Если модель вернула в блоке ` ```JSON `:

```JSON
{ "error": "Не удалось распознать источник..." }
```

— исправьте ссылку или приложите текст рецепта и повторите. **Не добавляйте** такой объект в базу рецептов — CI его отклонит.

## Быстрый путь (только Cursor)

```
Добавь рецепт в data/recipes/.

Метод: [духовка / сковорода / гриль / тушение / кастрюля]
Продукт: [птица / говядина / крупы / …]
Источник: [ссылка]
Заметки: [конспект]

Следуй data/schemas/recipe.schema.json
```

## Где лежат файлы

Рецепты разбиты по **методу готовки** (папка) и **типу основного продукта** (файл):

```
data/recipes/
  index.json              — список всех файлов (сайт грузит отсюда)
  duhovka/                — духовка / запекание
    ptitsa.json
    govyadina.json
  skovoroda/              — сковорода / обжарка
    govyadina.json
  grill/                  — гриль / мангал
    govyadina.json
  tushenie/               — тушение / долгое томление
    govyadina.json
    ptitsa.json
  kastryulya/             — кастрюля / варка на плите
    krupy.json
```

Каждый файл — **массив** объектов рецептов. Новый рецепт добавляется в подходящий файл; если файла ещё нет — создайте и пропишите путь в `index.json` → `files`.

| Метод (папка) | Когда использовать |
|---------------|-------------------|
| `duhovka` | Основное время в духовке (в т.ч. reverse sear) |
| `skovoroda` | Обжарка на сковороде |
| `grill` | Гриль, мангал, угли |
| `tushenie` | Долгое томление в кастрюле / казане |
| `kastryulya` | Варка круп, пасты, блюд «на плите» |

| Продукт (файл) | `category` в рецепте |
|----------------|----------------------|
| `ptitsa.json` | `птица` |
| `govyadina.json` | `говядина` |
| `krupy.json` | `крупы` |
| `pasta.json` | `паста` |
| `baranina.json` | `баранина` |
| `zavtrak.json` | `завтрак` |
| `desert.json` | `десерт` |
| `svinina.json` | `свинина` |
| `ryba.json` | `рыба` |
| … | см. список категорий ниже |

`id` рецепта должны быть **уникальны во всей базе**, не только в одном файле.

## Поля

| Поле | Обязательно | Описание |
|------|-------------|----------|
| id | да | Транслит русского title: `idealnyj-stejk-ribaj` |
| title | да | Название блюда |
| source_url | да | Главная ссылка на видео/статью |
| summary | да | Краткий конспект (2–4 предложения) |
| tags | да | 2–5 тегов, без дублирования `category` |
| source_type | нет | `video` или `article` |
| source_name | нет | Канал / сайт |
| category | нет | См. список ниже |
| ingredients | нет | Список |
| steps | нет | Шаги (строка или объект с таймером, см. ниже) |
| prep | нет | Напоминания заранее: разморозка, маринад, комнат. темп. |
| notes | нет | Нюансы, вторая ссылка, таймкоды |
| added | нет | YYYY-MM-DD |
| tried | нет | `true` — уже готовил сам (метка ✓ у названия на сайте). Ставится вручную, не через ИИ |

### Категории (`category`)

Допустимые значения (одно слово):

`птица`, `говядина`, `свинина`, `крупы`, `гарнир`, `суп`, `выпечка`, `десерт`, `соусы`, `завтрак`, `рыба`

## Подготовка заранее (`prep`)

Массив напоминаний до начала готовки. Показываются на странице рецепта и в режиме готовки с push-уведомлением.

```json
"prep": [
  { "text": "Разморозить лопатку в холодильнике", "before_hours": 12, "type": "thaw" },
  { "text": "Достать масло — комнатная температура", "before_min": 60, "type": "room_temp" },
  { "text": "Замариновать курицу", "before_hours": 24, "type": "marinate" }
]
```

| Поле | Обязательно | Описание |
|------|-------------|----------|
| text | да | Что сделать |
| before_min | * | За сколько минут до старта (одно из before_min / before_hours) |
| before_hours | * | За сколько часов до старта |
| type | нет | `thaw`, `fridge`, `room_temp`, `marinate`, `soak`, `custom` |

## Шаги с таймером (`steps`)

Шаг — строка или объект:

```json
"steps": [
  "Разогреть духовку до 200°C.",
  { "text": "Запекать до 62°C в бедре", "timer_min": 50, "timer_label": "Запекание" },
  { "text": "Отдых перед нарезкой", "timer_min": 15, "timer_label": "Отдых" }
]
```

| Поле | Описание |
|------|----------|
| text | Текст шага |
| timer_min | Минуты таймера |
| timer_sec | Секунды (дополнительно к timer_min) |
| timer_label | Подпись на кнопке таймера |

## Несколько рецептов из одного источника

Модель может вернуть массив внутри блока:

```JSON
[
  { "id": "domashnij-majonez-blender", ... },
  { "id": "klassicheskij-sous-tartar", ... }
]
```

Передайте ответ целиком в Cursor. Каждый объект проверяется отдельно; `id` должны быть уникальны внутри массива и не совпадать с уже существующими в базе.

## После добавления

```bash
node scripts/validate-recipes.js
python -m http.server 3456
```

Проверить: вкладка «Рецепты», `recipe.html?id=...`
