## 1. Две версии в одном репо

| | V1 сейчас | V2 в `v2/` |
|--|-----------|------------|
| Что | статический HTML + JSON | Next.js 15 + Django 5.2 + PostgreSQL |
| Корень | `index.html`, `recipe.html`, `js/`, `css/`, `data/` | `v2/frontend`, `v2/backend`, `v2/infra` |
| Как смотреть | `python -m http.server 3456` из корня | `docker compose -f v2/infra/docker-compose.yml up --build` → http://localhost:8080 |
| Прод | GitHub Pages, `sol-chef.ru` | Timeweb, тот же домен **после** cutover |

Пока cutover не сделан: не удалять корневой сайт, не менять `data/` «под V2», не класть Next/Django в корень, не публиковать V2 на Pages.

Cutover: DNS/Caddy на VPS, 301 со старых URL, JSON в архив, без dual-write. Корневой HTML можно оставить в git как архив.

## 2. Продукт 2.0 (первый срез)

Read-only паритет с V1, без аккаунтов. Живой V1 (снимок чисел — [DEFAULTS.md](DEFAULTS.md)): 21 крупа, 3 мяса, 10 секций советов; калькулятора и печати в V1 нет; дефолт главной — каталог; на телефоне уже три раздела.

- Справочники: крупы, говядина, свинина, птица, советы Энди. V1 JSON → ETL → Postgres (`content_documents`). Ниши с рецептами после импорта — живые фильтры; пустых гидов и «скоро» не делать.
- Каталог: **весь текущий каталог V1** импортируется в БД сразу, `/recipes/<slug>` из Postgres, cook mode, «У меня». Печати нет. Next не читает `data/recipes/*.json`.
- 301 с `recipe.html?id=…`.
- **Калькулятор** (имя временное, HUMAN 3.15): `/calculator` для подбора и шаринга. Главная `/` — витрина (вход + случайные рецепты и советы), не копия калькулятора. Считает Django. Не путать с «У меня» на рецепте. Разбор: [CALCULATOR.md](CALCULATOR.md).
- Поиск: `to_tsvector('russian')` + `pg_trgm` + `ё`→`е`.
- Токены — копия из [`css/global.css`](../../css/global.css), корень не перезаписывать.
- Навигация: **D+** в [UX-PROPOSAL.md](UX-PROPOSAL.md). Код только [`v2/`](../).

### 2.1. Экраны среза

`/` витрина (вход + лучшие) · `/calculator` · `/grains` · `/meat` · `/meat/beef|pork|poultry` · `/tips` · `/recipes` · `/recipes/<slug>`.

Не в первом срезе: аккаунты, комментарии, фото, Postbox, S3 РФ, волны рецептов, V2.1+, деплой на VPS, юридические тексты «под ключ».

Имя в шапке: «Кухонная шпаргалка» / sol-chef. UI только русский. Код и API — английский.

## 3. Стек и маршруты

Подробно: [ARCHITECTURE.md](ARCHITECTURE.md). Числа: [DEFAULTS.md](DEFAULTS.md).

Django владеет данными, сессией, CSRF, масштабом и калькулятором. Next — SSR, без формул `ratio^0.7` на клиенте. Без JWT и CORS. Срез: postgres + redis + Django + Next + Caddy; без Celery/MinIO/Mailpit. Сборка образов только в CI. ClamAV не ставить.

## 4. Данные

Контракт: [DATA-MODEL.md](DATA-MODEL.md). Кратко: живые поля на `Recipe`, ревизии для истории, якорь `is_anchor`, аллергены с `canonical_id`, справочники — `ContentDocument`, `unknown` ≠ «нет». `gentle` = `ratio^0.7`, не формула V1 JS. Нет servings и якоря — масштаб выключен.

ETL: dry-run / import / report; каталог V1 (DEFAULTS) **плюс** новая сотня, не «внутри 100» (HUMAN §5.1). Папки V1 `data/recipes/duhovka/` до cutover не переименовывать. Свободных тегов V1 — 85, не 76.

## 5. Калькулятор

Один domain service в Django. Next **не** реализует масштаб и ранжирование на клиенте (даже «для отзывчивости»). Формулы только в Django, золотые тесты — pytest.

Жёсткий отсев: unpublished, аллерген `contains` или `unknown`, нет основы/оборудования. Веса v0 — в DEFAULTS, пока HUMAN §4 пуст. `unknown` по молоку не проходит фильтр «без молока».

В рассчитываемых строках нет стакана. Простой pantry (`have=`) сравнивает факт наличия канона, не граммы. Граммы — только при плотности и только в V2.2.

## 6. Аккаунты (V2.1)

План разработки: [ACCOUNTS.md](ACCOUNTS.md). Поля — DATA-MODEL. HTTP — API. Экраны — UX-PROPOSAL §13. ADR — DEC-025.

Гость остаётся полным продуктом. Аккаунт — память (избранное, готовил, кладовка-факт) и голос (оценка, комментарий, жалоба).

- Только российские почтовые TLD (не Gmail). Госуслуги и телефон не делать.
- GET по ссылке из письма не логинит и не сжигает токен. Вход — POST кнопки или OTP. В БД только хеш.
- Комментарии: plaintext, премодерация первых 5, стоп-слова, жалоба человеку. Подпись «Участник · дата».
- Фото только к «я приготовил» — **V2.2**, карантин на worker.
- Юрист 152/149/406 ещё не смотрел — код следует HUMAN, заключение не закрыто. Удаление аккаунта в V2.1-A есть сразу.

Спринты: **V2.1-A** личность (Mailpit, вход, выход, забыть меня) → **B** память → **C** голос. Не мешать с граммами кладовки.
