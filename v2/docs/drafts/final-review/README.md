# Пакет финальной проверки — сентябрь 2026

Не канон. Не меняет RECIPE / CALCULATOR. Экраны — [UX-PROPOSAL.md](../../UX-PROPOSAL.md); сборка наборов — [WEEKLY-PREP-DESIGN.md](../../weekly/WEEKLY-PREP-DESIGN.md) §28–40. Это **выгрузка для человека**: что написано и как это лежит на экране.

Сайт: `http://localhost:8080`.

## Как отдать на проверку

Семь самостоятельных файлов. Можно слать по одному рецензенту.

| Файл | Кому | Что проверять |
|------|------|----------------|
| [01-new-recipes.md](01-new-recipes.md) | редактор карточек | семь новых рецептов: шаги, граммы, русский, заметки |
| [02-tips.md](02-tips.md) | редактор гида | все советы шеф-поваров, как на `/tips` |
| [03-calculator.md](03-calculator.md) | продукт / логика | как считает подбор, с примерами на этих карточках |
| [04-text-rules.md](04-text-rules.md) | автор / модератор | правила текстов рецептов и UI |
| [05-pages.md](05-pages.md) | UX / вёрстка | раскладка каждого экрана + один пример контента |
| [06-kit-dlya-zanyatykh.md](06-kit-dlya-zanyatykh.md) | редактор «На неделю» | набор «Для занятых» целиком: закупка, вс, слоты, «Без вчерашнего» |
| [07-kit-byudzhetnaya.md](07-kit-byudzhetnaya.md) | редактор «На неделю» | набор «Бюджетная» целиком |

Сводка с примерами рецепта, совета, двух наборов и выдачи калькулятора — [00-EXAMPLES.md](00-EXAMPLES.md). Это «один большой файл», если удобнее смотреть всё сразу.

**Весь каталог V2 (135 карточек)** — только тексты (название, описание, ингредиенты, шаги, заметки), один файл: [recipes/all.md](recipes/all.md).

**Оба набора «На неделю»** — тексты с живой страницы (закупка, воскресенье, боксы, слоты, «Без вчерашнего»), один файл: [prep/all.md](prep/all.md).

Накопитель правок из нескольких чатов, чтобы потом пройти оставшиеся карточки: [EDITORIAL-PASS.md](EDITORIAL-PASS.md). Дописывать туда, не плодить второй файл.

Старые волны 1–9 и 43 карточки V1 **не** повторяем в файлах 01–07: они уже проверены. Полная выгрузка — отдельным пакетом в `recipes/`.
