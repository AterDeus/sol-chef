# Часть 5. Страницы: раскладка и один пример контента

Как лежит на экране, сверху вниз. Десктоп: шапка. Телефон (≤768): бренд над контентом + таббар внизу. Рецепт на телефоне: свой таббар (назад · справка · режим готовки).

Иконка + подпись у каждого пункта шапки и таббара. Не голый текст и не иконка без лейбла.

---

## Шапка и низ (везде, кроме оверлея готовки)

**Десктоп, шапка**

```
[шляпа] Кухонная шпаргалка     [фильтр] Калькулятор  [книга] Рецепты  [холодильник] На неделю  [колос] Справочник  [шляпа] Советы
```

Логотип → `/`. Активный пункт подчёркнут. На главной активен бренд, не пункт меню.

**Телефон, таббар** (5 колонок)

```
Калькулятор | Рецепты | На неделю | Справка | Советы
```

На справочнике подпись короче: **Справка** (`aria`: Справочник).

**Футер** (нет на странице рецепта)

```
Крупы · Говядина · Свинина · Птица · Советы шеф-поваров · На неделю · Все рецепты
```

На `/grains` и `/meat*` вторая полоска: Крупы · Говядина · Свинина · Птица.

## 2. Калькулятор `/calculator`

Пустой вход — только вопрос.

```
Подбор
Калькулятор
Напишите, что есть дома, или выберите, что сейчас важнее. Система сама
соберёт блюдо и подскажет, почему.

Что есть дома
┌────────────────────────────────────────────┐
│ курица, гречка, лук                        │
└────────────────────────────────────────────┘
[Найти из этого]

Что есть
Сначала группа, внутри неё — уточнение. Несколько групп не смешиваются.
[Курица] [Мясо] [Рыба] [Овощи] [Крупы] [Яйца] [Молочное] [Другое]

Что сейчас важнее
[Быстро] [Из того, что есть] [Проще] [На несколько дней] [Полегче] [В духовке]

▸ Ещё условия     (свёрнуто: Без чего / Посуда)

Пока ничего не выбрано — напишите продукты или ткните сценарий.
```

**Пример после запроса** `?have=canned_tuna&intent=fast`

Чип Рыба раскрыт карточкой; в **Выбрано** путь к тунцу.

```
Начать заново · Книга рецептов

Я бы приготовил
Боул с горбушей или тунцом
[Консервированная рыба] [Без термообработки] [N шагов]
Нужно докупить: рис, огурец, помидор

Почему именно это
  ✓ есть рыбные консервы
  ✓ быстрее на плите
[Приготовить]

Ещё варианты
Быстрее     Баклажаны с картофелем на сковороде    быстрее на плите
Проще       Боул с нутом и запечёнными овощами     меньше стоять у плиты
Ещё вариант Лобио из красной фасоли (быстрое)
```

Нет Score. Нет сетки каталога. Клик «Приготовить» → карточка с теми же осями.

## 5. Режим готовки (оверлей на весь экран)

Шапка оверлея: закрыть · **Режим готовки** / название · «не гасить экран».

**Setup**

```
Когда начнёте?     [Сейчас] [Запланировать]
Заранее            (если в рецепте есть prep)
N шагов · N с таймером
[Начать готовку]   [Только напоминания]  ← если есть prep
```

**Шаги, телефон:** крупный текст · таймер старт/пауза/сброс · ± пока не бежит · «Шаг выполнен» · Назад / Далее · внизу `<details>` Все шаги.

**Шаги, стол ≥769:** слева текущий шаг и таймер; справа лента всех шагов (текущий выделен, выполненные зачёркнуты).

Конец: **Готово!** + название + Закрыть.

Пример шага 1 боула с нутом: «Разогреть духовку до 220 °C…»

**Вкладка Что купить** (пример строк, база на двоих)

| Продукт | Количество |
|---------|------------|
| Голяшка | 600 г |
| Куриный фарш | 700 г |
| Куриное бедро без кости | 400 г |
| Филе минтая | 450 г |
| Свёкла | 400 г |
| Капуста белокочанная | 1600 г |

**Вкладка Подготовить в воскресенье**

Лид: *Готовый суп сегодня не варите: нужен бульон, зажарка и нарезка. Рис не трогайте — он варится пятнадцать минут в день еды…*

Нумерованные шаги с часами: `00:00` Разогрейте духовку до 220 °C. Голяшку залейте холодной водой…

Таблица **Куда разложить:** подпись «N контейнеров плюс банки в шкафу» (банки не в счёте). Колонки Бокс · Что · Где · Достать. Пример: `№2 котлеты, холодильник` · … · Холодильник · — ; `№3 котлеты, морозилка` · … · Морозилка · **вечером накануне четверга**; противень овощей · **утром среды**.

`<details>` Подробнее по каждой заготовке.

**Вкладка Блюда на неделю**

Семь колонок дня, в каждой обед и ужин. На карточке: глагол · Обед/Ужин · **название тарелки** · состав.

```
Пн
  Доготовить  Обед   Борщ со сметаной и чесночным тостом
                     Борщ с говядиной, сметана, бородинский с чесноком
  Доготовить  Ужин   Котлеты с гречкой и салатом из капусты с огурцом

Вт
  Разогреть   Обед   Борщ со сметаной и хлебом     ← без галочки «Без вчерашнего»
  Доготовить  Ужин   Шакшука с фетой и хлебом
…
Пт
  Доготовить  Обед   Боул с рисом и рыбой из банки
  Доготовить  Ужин   Тушёная капуста с курицей
```

## 10. Мясо `/meat` и `/meat/beef`

## 11. Советы `/tips`

Хендбук: поиск и чипы на уже загруженном JSON, без нового API. Плитка карточек (`hint` + бейджи). Описание — абсолютный слой поверх сетки (соседи не едут); открыта одна.

```
Советы шеф-поваров
Советы
сгруппированные по темам. Свёрнуто по умолчанию — раскрывайте нужный блок.

Что хотите узнать?
[ Например: бисквит, мука, заморозка, духовка ]

Разделы
[ Подготовка и организация ] [ Ножи… ] [ Сковорода… ] …
Тип
[ Приём ] [ Ошибка ] [ Время ] [ Точность ] [ Температура ] [ Хранение ]

Подготовка и организация
┌ Приём · Подготовка ┐  ┌ Приём · Подготовка ┐  ┌ Время · Подготовка ┐
│ Прочитайте весь    │  │ Подготовьте        │  │ Не начинайте       │
│ рецепт от начала…  │  │ продукты до того…  │  │ сложный рецепт…    │
│                    │  └────────────────────┘  └────────────────────┘
│ описание поверх    │
│ сетки, рамка одна  │
└────────────────────┘
```

Полный текст — часть 2. Ссылка с главной: `/tips#tip-{item.id}`. Шаринг поиска: `/tips?q=&kind=&section=`.
