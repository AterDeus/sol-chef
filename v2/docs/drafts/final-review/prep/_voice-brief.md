Не канон. Рабочий бриф на один проход. Источник экрана: `all.md`. Источник правки: JSON наборов, не этот файл.

## Задача

Переписать **человеческие** тексты двух наборов так, чтобы они звучали как спокойная речь соседа на кухне: законченные предложения, повелительное «вы», обычные кухонные слова.

Не менять факты: граммы, минуты, °C (63 рыба, 74 фарш/полоски/разогрев волокон), какой бокс в какой день, холодильник vs морозилка, что варят в воскресенье и что нет.

Не трогать код, `all.md`, JSON. Только файл своего прохода.

## Что человек уже назвал ужасом

1. «Уберите плоским пакетом в морозилку. Капусту сегодня не тушите.»
   - «плоским пакетом» — канцелярит способа; сказать: сложите тонким слоем в пакет и уберите в морозилку.
   - Вторая фраза про капусту в шаге **куриных полосок** — чужая заготовка. Убрать. Капусту к пятнице режут в будни — это пишется в шаге пятницы, не здесь.

2. «Утром достаньте из морозилки №4 противень»
   - Противень — лист духовки. В морозилке лежит **контейнер** с запечёнными овощами.
   - Читается как «морозилка номер 4». Нужно: «достаньте из морозилки контейнер №4».
   - Подпись бокса: `№4 запечённые овощи`, не `№4 противень`.
   - Заголовок компонента: «Запечённые овощи», не «Противень овощей».
   - В шаге воскресенья слово «противень» **можно**: на него выкладывают. В хранении и оттайке — нельзя.

3. «Если есть термометр — в центре 63 °C; без термометра филе должно стать матовым… К тарелке — хлеб.»
   - Сначала вид и вилка, градусы факультативно. Не протокол SAFETY.
   - «К тарелке — хлеб» — телеграф. «Подайте с хлебом.»
   - То же для 74 °C у фарша и полосок: сначала разлом самой толстой, потом «если есть термометр».

## Ещё ломается русский (чинить)

- Телеграф: «Хлеб и зелень.» / «Хлеб к тарелке.» / «Сметана в тарелку.» / «Рис к мясу.» / «С огня — ложка масла» / «Пакет — в морозилку» / «Кастрюлю — в баню» / «Салат: капуста с огурцом».
- Внутренний жаргон: слот, чип, leftover, «слот ближайший», «двумя боксами» (писать «контейнерами»). «не из бокса» в буднях можно оставить — это разрешённая формула.
- Место хранения в ярлыке, если оно дублирует колонку и ломает фразу оттайки: `№3 котлеты, морозилка` → `№3 котлеты`. Номер + содержимое. День недели в ярлыке нельзя.
- «фарш должен полностью измениться» → внутри не сырой, цвет и вид готового фарша.
- «Не сушите вкрутую» → яйца не пересушивать, омлет ещё мягкий.
- «разогрейте до пара» → до горячего, пусть слегка парит / до кипения — по смыслу соуса.
- P13: не спорить с призраком. «Без капусты это не ужин.» / «Это другая тарелка, не капуста со вчера.» / «Яйца сегодня не кладите.» — убрать или заменить смыслом готовки.
- «Кислая капуста держит эту тарелку» — не говорить так.
- Дробь на экране через запятую: `1,5 см`, не `1.5 см`.
- Воскресенье: дни недели в шагах вс не писать («на понедельник», «слот ближайший»). Будни: «вчерашний борщ» можно.
- Не писать «на двоих» в шагах.

## Что оставлять, если уже хорошо

Не «улучшать» спокойное предложение ради стиля. Если фраза уже литературная — `KEEP`.

Противень как посуда в вс — KEEP. Водяная баня — KEEP. «неглубокие контейнеры» — KEEP.

## Оттайка

Фразы «С вечера… достаньте из морозилки LABEL» собирает код из `label`. Поэтому `label` обязан быть «№N содержимое», без слова «морозилка/противень/холодильник». Предлагай ярлыки; шаблон «контейнер №N» напиши в блоке LABELS — оркестратор поправит генератор.

## Формат выхода

Один markdown. Для каждой правки:

```
### path
kit / поле / идентификатор (id компонента, day+meal, t_min)
BEFORE: «…»
AFTER: «…»
WHY: одно предложение
```

В конце:

- `## LABELS` — таблица старый ярлык → новый (оба набора)
- `## KEEP` — что сознательно не трогал
- `## RISK` — где не уверен

Не копировать весь JSON. Не выдумывать новые продукты, URL, температуры ниже SAFETY. Не ставить editorial_tested.
