# WEEKLY-PREP-DESIGN.md

Статус: **рабочая спецификация создания недельных наборов.**

Главная задача документа: заставить редактора/агента проектировать **хорошую неделю как готовую систему питания**, а не красивую коллекцию заготовок и не набор текстов.

Набор — не 14 карточек и не шкала воскресенья. Это логика хранения, последовательность заготовки, реалистичное время, повтор боксов и понятность для новичка. Если эти слои не сходятся, красивые шаги не спасают.

Связанные документы:
- [MEAL-CONTRACT.md](MEAL-CONTRACT.md) — тарелка; порядок meal → day → week → prep; reheat N+1
- [NUTRITION-FRAMEWORK.md](NUTRITION-FRAMEWORK.md)
- [SEASONALITY-RU.md](SEASONALITY-RU.md)
- продукт: [../drafts/WEEKLY-PREP.md](../drafts/WEEKLY-PREP.md)
- карта сущностей — § ниже и продукт [WEEKLY-PREP.md](../drafts/WEEKLY-PREP.md)
- контракт JSON и **голос текстов**: [../drafts/WEEKLY-PREP-TZ.md](../drafts/WEEKLY-PREP-TZ.md) §8
- [../SAFETY.md](../SAFETY.md)

# 0. Главная формула

Набор проектируется **от рациона к заготовке**.

Продукт слоя — **component meal prep**, не batch cooking.

Batch cooking: несколько больших кастрюль в вс, будни в основном разогрев той же еды. Эксперимент №0 (набор 2) показал, что одна духовка и два гуляша дают стену ~5,5 ч при мизерной экономии активных минут.

Component meal prep: заготовить основу → быстро превратить её в **разные** будничные блюда.

Главный редакционный критерий:

> минимальное количество воскресной работы, которое создаёт максимальное количество разных быстрых будничных блюд.

Не минимизировать SKU. Не максимизировать повторы. Не максимизировать арифметическую экономию минут. Не «использовать всё купленное».

Цель:

> хороший недельный рацион при минимально разумном объёме кухонной работы и отходов.

Центральный порядок — [MEAL-CONTRACT.md](MEAL-CONTRACT.md) §0.1: **meal → day → week → prep**. Не наоборот. Сезон и характер недели — рамка, не предлог размазать остатки курицы.

```text
сезон + характер недели          ← рамка, не склад сырья
↓
каждый слот по MEAL-CONTRACT     ← сначала тарелка
↓
проверка дня                     ← обед/ужин, protein_primary
↓
проверка недели                  ← NUTRITION-FRAMEWORK
↓
общие ингредиенты → компоненты → контейнеры → вс
```

Нельзя начинать с:

> У нас есть 2 кг курицы — давайте сделаем 14 блюд.

Нижний слой (компоненты, контейнеры, слоты, `steps`, `reheat`, `weekend_timeline`) не выбрасывается. Он выполняется **после** тарелок, дня и недели.

# 1. Что является хорошим набором

Хороший набор:
- является полноценной редакционной неделей, даже если убрать prep;
- разнообразен по источникам белка, и один белок не визуально доминирует неделю;
- содержит овощи ежедневно;
- учитывает сезонность;
- использует общие продукты разумно;
- превращает часть продуктов в компоненты, а не в несколько одинаковых кастрюль;
- не требует хаотичной воскресной готовки;
- даёт будничные слоты ≤20 минут активной работы;
- не держит опасные продукты слишком долго;
- не заполняет 14 слотов любой ценой, в том числе чистыми гарнирами;
- имеет консервативные сроки холодильника; всё дальше — через морозилку;
- явно учит, что не готовить в воскресенье и зачем;
- честно считает ручные минуты и посуду;
- новичок понимает систему, а не только «шаг 3».

Приоритеты:

```text
безопасность
>
вкус
>
питательная структура
>
разнообразие
>
сезонность
>
выполнимость воскресенья
>
скорость будней
>
экономия SKU/денег
```

# 2. Шаг 1 — выбрать сезон и характер недели

Сначала определить:
- месяц/сезон;
- доступные свежие продукты;
- продукты хранения;
- разумную долю заморозки;
- тему недели.

Примеры тем:
- летняя свежая;
- осенняя;
- зимняя;
- весенняя.

Первый срез не должен превращаться в каталог из шести фильтров. Тема — редакционная характеристика набора.

---

# 3. Шаг 2 — построить 14 тарелок БЕЗ slug

Это шаг **meal**, не закупка. Сначала обед и ужин как еда, потом проверка дня и недели. Не заполнять клетки тем, что удобно заготовить.

Сначала таблица:

| День | Обед | Ужин |
|---|---|---|
| Пн | рыба + крупа + овощи | птица + овощи |
| Вт | бобовые + овощи + хлеб | яйца + овощи + хлеб |
| Ср | мясо (суп) + хлеб | рыба + крупа + овощи |
| Чт | боул (бобовые/тыква) + сыр + хлеб | птица + овощи + крупа |
| Пт | рыба + крупа + овощи | мясо/птица + овощи |
| Сб | бобовые + овощи + крупа/хлеб | паста + мясной соус + овощи |
| Вс | суп + хлеб | яйца + овощи + хлеб |

Это только пример формы. Рыба здесь Пн / Ср / Пт — не соседние календарные дни. Конкретная неделя — по `NUTRITION-FRAMEWORK.md` и `MEAL-CONTRACT.md`.

Проверить до поиска рецептов:
- белок;
- овощи;
- зерновые/крахмалистые продукты;
- рыбу;
- бобовые;
- яйца;
- молочные/кисломолочные;
- полезные жиры;
- разнообразие овощных групп.

---

# 4. Шаг 3 — подобрать существующие рецепты

Для каждого слота:
1. найти подходящие published slug;
2. прочитать фактические `ingredients`, `steps`, `prep`, `notes`;
3. проверить соответствие пищевой роли;
4. проверить сезонность;
5. проверить, реально ли построить из него будничную версию.

Не создавать новый slug только ради заполнения сетки. Не генерировать рецепт «заодно».

Если подходящего рецепта нет:

```text
ДЫРА КАТАЛОГА
```

и записать её в анализ.

---

# 4.1. Пять конструкций, не коллекция slug

Пилот сентября дал кирпичи. **Не** генерировать следующую пачку рецептов, пока две недели не собраны из этих конструкций:

1. **Холодный боул** — готовый белок (часто банка) + крупа + свежие овощи.
2. **Тёплый овощной боул** — заготовленный овощ + бобовые + сыр + хлеб; жир не стопкой (масло готовки + финиш **или** орехи).
3. **Заготовленное мясо** — мясной компонент + быстрый гарнир слота (капуста / крупа обязательны, не «мясо голое»).
4. **Быстрое бобовое блюдо** — банка + вкусовая база + хлеб + свежий vegetable companion снаружи карточки.
5. **Заготовленный соус/основа** — например шакшука: яйца в день еды.

Конструкция важнее конкретного slug. Новый рецепт — только если кирпича в каталоге нет.

---

# 5. Шаг 4 — проверить неделю как рацион

Каждый слот сначала прогнать по [MEAL-CONTRACT.md](MEAL-CONTRACT.md). Не прошедший тарелку слот не спасают заготовки.

До prep построить таблицу:

```text
день → обед → ужин
```

и отдельно:

```text
белки
овощные группы
крупы
бобовые
рыба
яйца
молочные
жиры
```

Провалить неделю, если она становится хорошей только благодаря удобству заготовок.

Главный тест:

> Если убрать всю оптимизацию prep, останется ли это разумной неделей питания?

Если нет — начинать заново.

# 6. Шаг 5 — найти пересечение продуктов

Теперь искать общие ингредиенты.

Например:

```text
лук
морковь
капуста
сезонный овощ
крупа 1
крупа 2
птица
рыба
бобовые
```

Но не удалять новый продукт только ради уменьшения SKU, если он нужен для:
- рыбы;
- бобовых;
- разнообразия овощей;
- другого важного источника питательных веществ;
- заметного изменения вкуса.

---

# 7. Шаг 6 — сформировать компоненты

Хороший компонент:
- используется минимум в 2 слотах;
- реально экономит работу;
- безопасно хранится;
- имеет понятное состояние готовности;
- не ухудшает вкус будущих блюд.

Примеры:
- полуготовая птица;
- приготовленная крупа;
- запечённые овощи (не крестоцветные на дальние дни без бланша/мороза);
- зелёная/коричневая чечевица, нут, фасоль;
- томатная основа, матбуха;
- рыбные котлеты сырьём в морозилку.

Плохой компонент:
> нарезать один огурец в воскресенье ради одного салата в четверг.

---

# 8. Не всё готовить в воскресенье

Разделить продукты на:

### Подготовить заранее
- корнеплоды, капуста, запечённые овощи не из крестоцветных на дальние дни;
- суповые/тушёные основы **не из рыбы** на дальние дни, **без** варёного картофеля в кастрюле;
- безопасную полуготовность птицы/мяса (считать сырым);
- томатную/перечную основу, бобовое рагу, рыбные котлеты сырьём в морозилку;
- зелёную/коричневую чечевицу, нут, фасоль — не красную чечевицу впрок.

Крупу впрок класть только если её едят в ближайшее холодильное окно (§29) и остудили пластом. Для боула и гарнира слота **рис варить свежим в день еды** — и ради вкуса, и ради *Bacillus cereus* ([SAFETY.md](../SAFETY.md)). Не делать воскресный бокс варёного риса «на неделю».

### Не готовить в воскресенье
- белую рыбу до готовности (треска, минтай): в вс только порции или маринад; будни — `finish` 10–12 мин;
- яйца вкрутую «на неделю», омлет, глазунью;
- жареный картофель;
- картофель в борщ/суп: резать и варить **в день еды** (текстура и срок готового супа);
- пасту до готовности (варить в будни или очень глубокое al dente + масло);
- рис к боулу и гарниру слота;
- нарезку помидора/огурца/зелени на дальние дни.

### Оставить свежими / комнатной температурой
- помидоры на салат — не в холодильник, резать в момент еды;
- огурцы, зелень, свежие фрукты.

### Купить/открыть в будни
- консервы тунца/горбуши в с/с — `assemble` в слот, банку не вскрывать в вс;
- консервированные нут/фасоль — pantry, 30 секунд, не варить сухую фасоль 2 часа без нужды;
- рассольный сыр к салату.

# 9. Шаг 7 — контейнеры и логистика

Контейнер создаётся ради будущего действия.

Хорошо:

```text
№1 курица 400 г → Пн
№2 курица 400 г → Ср
№3 курица 400 г → Пт
```

Плохо:

```text
№1 курица 1400 г
```

если человек должен сам решать, как её делить.

Для каждого контейнера нужны:
- компонент;
- количество + единица;
- место хранения;
- день разморозки;
- слоты, которые его используют.

---

# 10. Шаг 8 — freezer/fridge

Каждый компонент проверять:
- `fridge_days`;
- `freezer_days`;
- `place`;
- `thaw_before_day`;
- качество после разморозки;
- необходимость свежей доготовки.

Ориентир бытового холодильника: **не больше 8–10 контейнеров** на набор (примерно 2 полки холодильника + 1 ящик морозилки). Закрытые магазинные банки **не** входят в этот счёт и не называются боксом. В шапке таблицы: «N контейнеров плюс банки в шкафу», не «N+1 боксов».

Разморозка — не один шаблон «с вечера». Жидкость ~1 л при +4 °C — **24–36 часов**. Плоский пакет котлет/филе — вечер накануне. Нарезанные запечённые овощи оттаивают за несколько часов: утро дня слота, не с вечера вместе с мясом. Подробнее §32.

Не морозить: варёный/запечённый **кусковой** картофель (ретроградация крахмала → вода и крупа); готовую белую рыбу (волокна-губка). Рыбные котлеты/тефтели морозить сырыми или полуготовыми — да.

Не строить неделю на предположении, что всё спокойно пролежит 7 дней в холодильнике.

Консервативное окно холодильника для **готовой** еды — **3 суток**, максимум 4 при явной рецептурной логике. Не писать «срок хранения: 6 суток» как норму редакции. Слот с четверга и дальше от воскресной варки — через морозилку, если это не `reheat` блюда, сваренного в будни. Таблица и банки — §29–31.

---

# 11. Шаг 9 — будничный слот

Каждый слот должен отвечать:

> что достать → что сделать → что получить.

Пример:

```text
12 минут
№2 + №5
1 сковорода

1. достать;
2. добавить свежий компонент;
3. доготовить;
4. довести до целевой температуры;
5. подать.
```

Пользователь не должен читать половину книжного рецепта.

---

# 12. 10–20 минут

Считать `time_active_from_prep_min`.

Не считать:
- выполненную воскресную работу;
- разморозку в холодильнике;
- чистое пассивное ожидание, когда человек свободен.

Считать активностью всё, где человек обязан работать или постоянно контролировать процесс.

Слот >20 минут активной работы:
- переделать;
- либо исключить из набора.

# 13. Режимы

Использовать только:

```text
assemble
finish
reheat
```

## `assemble`
Полуфабрикат уже готов к употреблению. Человек только соединяет, нарезает, собирает. Нет обязательной термической обработки.

Примеры: лаваш с готовой птицей; салат из уже нарезанных/запечённых овощей.

## `finish`
Нужна термическая обработка: довести до целевой температуры SAFETY, сварить крупу/лапшу, прогреть полуфабрикат на сковороде.

Примеры:
- вс-бульон + разморозка + довести + сварить лапшу 6–8 мин → `finish`, не `assemble`;
- полуготовая птица до 74 °C → `finish`;
- вс-гуляш, который в будни греют на сковороде до 71 °C → `finish`, если прогрев — значимая часть работы.

## `reheat`
Готовое блюдо **осталось от предыдущего слота** и только разогревается.

Не использовать `reheat` для первого будничного появления воскресного контейнера: это `assemble` или `finish` в зависимости от реальной работы.

Не маркировать `assemble` слот, где человек обязан греть, варить или доводить до SAFETY. Подписи в UI («Собрать · 8 мин» / «Доготовить · 15 мин» / «Разогреть · 10 мин») должны совпадать с реальной работой.

# 14. Воскресная подготовка

Сначала разместить длинные пассивные процессы:
- духовка;
- варка;
- тушение;
- охлаждение.

Затем заполнять паузы работой рук.

Ресурсы по умолчанию:
- 1 человек;
- 1 духовка;
- 2 конфорки;
- 1 пара рук.

Не скрывать обязательное охлаждение. Канон: [SAFETY.md](../SAFETY.md) (крупы, полуготовность, жидкости, фасовка в мороз).

Крупы: остужать **тонким слоем**, в холод как можно скорее. Не оставлять кастрюлю риса/гречки на плите 3–4 часа.

Запечённые овощи: остужать **открытыми пластом**. Горячее под крышкой → конденсат → раскисшая масса.

Большой горячий объём (бульон ~1 л, соус, томлёное мясо) **не** снимать с огня «и сразу в морозилку». Не ставить кастрюлю кипятка в холодильник. Обязательный шаг шкалы: разделить на небольшие/плоские порции или холодная водяная баня → когда заметно остыло → холодильник; в морозилку только после этого. «Сразу уберите в морозилку» в `weekend_timeline` — брак набора, не стиль.

Не оптимизировать wall time за счёт опасного ускорения охлаждения и не вычёркивать охлаждение из ручных минут, если человека просят фасовать и носить кастрюли к раковине.

---

# 15. Экономия времени

Показывать:

```text
воскресная активная работа
будничная активная работа
те же приёмы с нуля
экономия
```

Но главным пользовательским сообщением считать:

> сколько работы убрали из будней.

Формула ценности, которую набор обязан уметь сказать человеку:

> Воскресенье: один раз готовим основу. Будни: 10–20 минут. Не нужно каждый день доставать нож, доску и думать, что приготовить.

Не рекламировать большой выигрыш, если арифметика показывает малую экономию. Ручные минуты воскресенья лучше **завысить**, чем занизить (§35).

---

# 16. Пересечение и остатки

После построения недели:
1. посчитать остатки;
2. проверить открытые упаковки;
3. проверить, можно ли использовать остаток в другом слоте;
4. решить, что лучше купить меньшей упаковкой;
5. решить, что заморозить.

Цель не «ноль остатков», а минимум бессмысленных остатков.

---

# 17. Замена слота

Основной вариант слота выбирает редактор. Альтернативы — **страховка**, не второй каталог.

Плохо: «Пятница, ужин — терияки / томат / сметана / овощи». Смысл набора — снять необходимость думать.

На слоте держать 0–2 альтернативы, не 3 «почти равноценных вкуса». Если три вкуса из одной птицы реально нужны — это три разных слота недели, а не выпадающий список одного вечера.

Альтернатива должна:
- использовать существующие компоненты;
- не требовать новой воскресной подготовки;
- не требовать новой закупки;
- сохранять пищевую роль слота;
- укладываться в 10–20 минут.

Нельзя заменять:

```text
рыба + овощи
```

на:

```text
чистая гречка
```

только потому, что гречка есть в контейнере.

# 18. Второй день

Для слоя «На неделю» `reheat` только на **следующий календарный день** (`source.day + 1`). Это правило продукта, не «еду вообще греют только завтра». Замороженный контейнер вс, который едят впервые в пятницу — `assemble`/`finish`, не `reheat` понедельника.

Нельзя: борщ в среду и разогрев в воскресенье. Борщ с картофелем не морозить ради этого.

`reheat` допустим только после проверки конкретного блюда:
- вкус;
- текстура;
- срок хранения;
- безопасность;
- качество после разогрева.

Не использовать правило «суп всегда на второй день».

Жёстко нет `reheat`:
- готовая белая рыба (запах, окисленный жир; в офисной микроволновке — табу);
- жареный картофель (хруст уходит за часы);
- омлет / яичница / яйца вкрутую старше ~48 ч;
- сметанные и йогуртовые соусы, которые тушили вместе с блюдом (сворачиваются, отсекают воду);
- красная чечевица (клейстер);
- паста, сваренная до готовности несколько дней назад.

Рыбный суп: только Д1 обед и Д2 обед `reheat`. Дальше не живёт.

Сметана/сливки/яйцо в горячем блюде: съесть в пределах **48 часов** после приготовления.

Холодную сметанную/йогуртовую заправку не тушить: `assemble` в тарелку к уже горячему.

# 20. Пограничные случаи кухни

Правила слотов. Не improvise «рыба 2–3 раза» готовым филе на пятницу.

## Рыба

Самый неудобный белок для prep. Полностью готовую белую рыбу не класть в контейнер «на неделю» и не морозить готовой.

Допустимые формулы:

| Формула | Вс | Будни | Mode |
|---|---|---|---|
| Филе сырое/дефрост | порции или маринад, не готовка | 10–12 мин сковорода / пергамент / «конверт» на овощах из вс; минуты — ориентир, готовность по толщине: мясо матовое, легко разделяется вилкой | `finish` |
| Рубленые котлеты/биточки | партия, морозилка | обжарить или разогреть | `finish` / `reheat` если уже довели |
| Консервы (тунец, горбуша с/с) | не открывать | банка + крупа + овощи + заправка | `assemble` |

Банка — закупка, не вс-готовка. `container_ids` слота — крупа/овощи из вс, не «бокс с открытыми консервами». Кладовую в схеме не заводить без отдельной фразы.
| Уха / сливочный рыбный суп | сварить | Д1 обед; Д2 обед только `reheat` | `finish` затем `reheat` |

Не закрывать «2–3 рыбы» третьим разогревом минтая в микроволновке.

## Молочное без завтрака

Не добирать кальций жирными сливочными соусами и «всем под сырной коркой».

- холодная заправка (сметана-чеснок, дзадзики, йогурт) — `assemble` к горячему;
- рассольный сыр кубиками (брынза, фета, сулугуни, адыгейский) в овощной слот;
- несладкая творожная запеканка / ньокки как белковый ужин, не как десерт.

## Бобовые

Не ставить 3–4 бобовых слота подряд: для непривычного ЖКТ это ловушка. Разносить дни, специи (кумин, кориандр, имбирь) по смыслу блюда.

Впрок: зелёная/коричневая чечевица, нут, фасоль — держат форму. Красная чечевица — в день варки или как суп-пюре, не кусковой leftover.

Консервы нут/фасоль — легальный pantry, не обязанность варить сухую фасоль 2 часа в вс.

## Крахмалы

- кусковой варёный/запечённый картофель не морозить;
- жареный картофель не `reheat`;
- паста: варить в будни 8–10 мин (`finish`) или в вс очень глубокое al dente + масло.

## Овощи

- крестоцветные (брокколи, цветная, белокочанная): сваренные в герметике к среде дают сероводород. В вс — бланш до полуготовности и шок-мороз **или** слоты Пн–Вт;
- помидор на салат: комната, нарезка в еду;
- запечённые: остужать открытыми.

## Яйца

Не белок «на воскресенье впрок». Вкрутую >48 ч — серый желток и резина. Омлет/яичница не `reheat`.

Будни 5–8 мин: глазунья на крупе с овощами; пашот; скрэмбл с заготовленными овощами; шакшука — яйца разбить в разогретую основу.

# 21. Пограничные случаи безопасности

Канон температур и охлаждения — [SAFETY.md](../SAFETY.md). Здесь — как это ломает kit.

- Крупа в глубокой кастрюле на столе 3–4 часа: риск токсина *Bacillus cereus*, кипячение его не убивает. Пласт, холод без долгого стола. Поэтому рис к боулу — свежий в слот, не вс-кастрюля на неделю.
- Полуготовая птица выглядит «уже едой». В карточке слота: считать сырым, отдельно от зелени, довести до 74 °C (без кости) / цели SAFETY. На карточке — домашний признак самой толстой части + факультативный термометр, не «сок прозрачный» как гарантия.
- Суп ~1 л: `thaw_before_day` с запасом 24–36 ч. Нарезанные овощи — утро слота, не общий «с вечера» с мясом.
- Горячий бульон/мясо «сразу в морозилку» — брак. Охлаждение: неглубокая ёмкость / баня → в хранение, не «когда перестало парить».
- `fridge_days` 6 у готового соуса / противня / капусты — брак, если нет мороза. §29.

# 22. Архетипы, которых не хватает каталогу

Не генерировать slug в этом проходе. Если каркас требует роль, а published нет — дыра в ANALYSIS.

Рыба, будничный `finish` 10–15 мин:
- филе в конверте / на подушке из вс-овощей;
- рубленые котлеты/биточки под морозилку;
- тёплый боул: крупа вс + консервы + свежие овощи + заправка.

Бобовые как основное, не только суп:
- томатное чили / рагу с фасолью (с фаршем или постное) — живёт 2–3 дня, хороший `reheat`;
- тёплый салат/боул: нут со специями 3 мин + запечённые овощи;
- густая чечевичная похлёбка / дал / суп-пюре.

Яично-овощные ужины:
- стир-фрай овощей из заготовки + яйца, ~7 мин;
- шакшука: вс-матбуха/перечно-томатная основа в банке → в будни яйца, ~8 мин.

Кальций без сливочного соуса:
- греческий / шопский / средиземноморский конструктор: свежие овощи + фета/брынза/тофу.

Плюс очередь эксперимента №0 (лаваш/боул с птицей, терияки из филе, соус-компонент, рваная говядина, leftover говяжьего гуляша, «мясной соус + паста»).

# 23. Чек-лист черновика

Прогнать **до** объявления kit готовым. Любой провал — переделать, не «набрать 14».

1. **Тарелка.** Каждый слот проходит [MEAL-CONTRACT.md](MEAL-CONTRACT.md): значимые роли, не галочки; CONTAINER_TEST; companions в `steps`. Порядок meal → day → week → prep. Роли primary / component / companion / leftover не перепутаны (§37).
2. **Белок.** Птица ≤4 из 14. Рыба 2–3 **приёма**, без двух **дней** подряд (`protein_primary`). Бобовые и/или яйца суммарно ≥2. Птица/говядина/свинина не длиннее двух дней подряд. Два соседних ужина на одной заготовке — две разные тарелки (§36).
3. **reheat.** Только день N+1. Нет борща через 4 дня.
4. **Рыба.** Готовая белая не впрок. Слоты — сырой `finish` / котлеты / консервы. Сырую рыбу «не морозят» не выдавать за общую норму: это решение **этого** набора, если слот ближайший.
5. **Разморозка.** Супы/рагу ≥~1 л: `thaw_before_day` с запасом 24–36 ч. Борщ с картофелем не морозить. День с оттайкой сам говорит, что достать: мясо и жидкость — с вечера, нарезка овощей — утром (§32). Не один шаблон на все боксы дня.
6. **Соусы и яйца.** Сметана в тарелку. Яйцо в горячем — 48 ч. «Желток как любите» — рядом полностью сваренный безопасный вариант.
7. **Контейнеры.** ≤8–10 физических контейнеров холода. Закрытые банки — шкаф, не в этом счёте.
8. **Крупы.** ≥2–3 вида. Рис к боулу — свежий в слот.
9. **Свежее.** Салат/огурец/зелень не из вс-нарезки на четверг.
10. **Parcook.** Полуготовая птица = сырое + температура. Фарш птицы: разлом самой толстой + факультативно 74 °C.
11. **Холодильник.** Готовое в холоде по умолчанию 3 суток; дальше — мороз. Нет «срок 6 суток» без технологии.
12. **Охлаждение.** Нет шага «горячее сразу в морозилку / холодильник».
13. **Воскресенье.** Посуда перечислена. Ручные минуты не занижены. Нет редакторского жаргона в текстах для человека.
14. **Без вчерашнего.** Видна цена: сколько блюд с нуля и сколько позиций к закупке.

# 24. Финальные ворота

## Питание
- овощи ежедневно;
- птица ≤4 слотов из 14; рыба 2–3 приёма, не два **дня** подряд; бобовые/яйца суммарно ≥2;
- птица/говядина/свинина не длиннее двух дней подряд; баранина как рыба;
- крупы: ≥2–3 вида;
- молочные без обязательного сливочного соуса (заправка / рассольный сыр / творожный слот);
- полезные жиры;
- нет пустого слота (только крупа или только овощи);
- нет очевидного доминирования одной группы.

## Сезон
- сезонные продукты используются логично;
- несезонные продукты имеют объяснимую причину;
- морозилка используется там, где это лучше свежего продукта.

## Кухня
- воскресенье выполнимо;
- чек-лист §23 пройден;
- storage / freezer / fridge / `thaw_before_day` разобраны;
- готовое в холодильнике ≤3 суток по умолчанию; дальние слоты через мороз;
- охлаждение перед холодом и морозом есть в шкале;
- ≤8–10 контейнеров; закрытые банки не бокс;
- посуда вс перечислена;
- будни ≤20 минут активной работы;
- ручные минуты вс не выглядят оптимистичной арифметикой;
- `reheat` оправдан физикой блюда, не желанием закрыть ячейку.

## Продукт
- неделя не выглядит складом контейнеров;
- блюда действительно различаются, в том числе при повторной основе;
- закупка является следствием недели;
- 14 слотов не заполняются любой ценой;
- новичок понимает, зачем картофель и рис не в воскресенье;
- «Без вчерашнего» показывает цену плана;
- ценность набора сказана человеком, не только минутами в шапке.

# 28. Набор — система недели, не пачка текстов

Редактор смотрит на готовый набор пятью слоями. Провал любого — переделка, не «подчистить формулировку».

| Слой | Вопрос |
|------|--------|
| Хранение | Что в холоде, что в морозе, сколько суток, когда открывать банку |
| Последовательность вс | Что параллельно, что остывает, что нельзя класть горячим |
| Время | Стена и руки правдоподобны для одного человека на обычной кухне |
| Боксы | Кто ест бокс, повтор без самодеятельности, дальние порции уже разделены |
| Новичок | Понятно зачем, не только что; нет внутреннего жаргона |

Не готовить всю неделю в воскресенье. Полуфабрикаты + сборка будней — правильная идея. Картофель супа, рис боула, яйца, свежая нарезка, сырая рыба/птица из мороза — типичные вещи, которые **специально** оставляют на слот. Это надо писать как обучение системе, не как умолчание.

# 29. Консервативные сроки холодильника

Ориентир leftover USDA: большинство готовых блюд и остатков **3–4 дня** в холодильнике. Для сайта берём **3 суток по умолчанию**, 4 — только если есть явная рецептурная логика (кислота, сухая капуста без лужи, и слот не дальше этого окна). Не 6.

Считать от момента, когда продукт стал готовым (воскресный вечер для вс-готовки).

| Что | Холодильник | Дальше |
|-----|-------------|--------|
| Готовый суп, соус, тушёное, запечённые овощи, готовая капуста | **3 суток** (до среды включительно от вс); после оттайки часы заново, и **по составу этой смеси**, не общим «противень 3 суток» | морозилка порциями |
| Сырые котлеты / фарш | **1–2 суток** | вторая партия сразу в мороз |
| Сырая рыба | **1–2 суток**; понедельник после покупки в вс — нормально | иначе мороз в вс |
| Сырая птица полосками | не держать до пятницы в холоде | мороз в вс |
| Открытые рыбные/бобовые консервы | **3–4 суток**, не в железной банке | съесть или выбросить |
| Закрытая магазинная банка | не холодильник | кладовая по условиям производителя |
| Варёный рис | лучше не впрок | варить в слот |

Конструкция «приготовили в воскресенье → едим в пятницу/субботу» **требует морозилки**, а не собственного срока редакции.

Не писать человеку «срок хранения: 6 суток», если это не отдельная технология конкретного продукта. Пометка «оценка редакции, не ГОСТ» не разрешает смелый срок.

`fridge_days` в JSON не больше этой таблицы. Если слот с четверга (день 4) ест вс-готовую еду — этот бокс `place: freezer`, если это не `reheat` блюда, сваренного уже в будни.

Гигантский бокс «соус на вторник и субботу» в одном холодильнике — брак. Делить: ближняя порция в холод, дальняя в мороз.

# 30. Охлаждение перед холодом и морозом

Системное правило всех наборов. Канон чисел — [SAFETY.md](../SAFETY.md).

Нельзя:

> снимите и сразу уберите в морозилку  
> лопатка готова → по пакетам → морозилка  
> остудите на столе часами, потом в холод

Нужно:

1. Переложить в неглубокую ёмкость или плоский слой **или** поставить кастрюлю в холодную водяную баню.
2. Быстро отвести тепло. Не ждать «комнатной температуры» часами на столе.
3. Убрать в холодильник или морозилку, не оставляя надолго на кухне. В морозилку — только после этого охлаждения.

Критерий — протокол (пласт / баня → сразу в место хранения), не пар над кастрюлей: блюдо может почти не парить и оставаться горячим внутри.

Это касается бульона ~1 л, соуса, томлёной говядины, любой большой кастрюли. Плоский пакет с уже остывшими котлетами — другое дело.

Шаг охлаждения обязан стоять в `weekend_timeline`, не в `storage.notes`. Не писать человеку «когда перестали сильно парить».

---

# 31. Банки

Закрытая промышленная банка — закупка и кладовая, не контейнер холодильника и не «неделя в холоде до открытия».

После открытия: переложить остаток в неметаллическую ёмкость, холодильник, съесть за 3–4 дня. Рыбу из банки открывать в день слота, если слот один.

Не писать бокс «№11 банки рыбы, закрытые, холодильник». В слоте: «банку откройте сейчас». Строка шкафа в таблице — не контейнер для закупки; в заголовке её не считать.

# 32. Разморозка — часть дня, не только таблица

Таблица «куда разложить» с колонкой «Достать» нужна. Этого мало.

Обязательная механика каждого набора: у дня, которому нужна оттайка, **в сетке блюд** явная фраза, **какую** система посчитала для этих боксов — не заставлять искать только в таблице.

Не один общий паттерн «всё достать с вечера». В одном наборе одновременно кусок мяса, пакет фарша, филе и противень кубиков — скорость разная.

Принцип (для алгоритма, не абзац человеку):

> Достать бокс, когда он успеет оттаять к готовке, и не раньше необходимого.

`thaw_before_day` — день первого слота, к которому бокс должен быть мягким (для ~1 л жидкости — день с запасом 24–36 ч). Подпись «с вечера / утром» **считает** UI из типа и размера, поле в JSON для этого не плодить:

| Тип | Пример | Когда доставать |
|-----|--------|-----------------|
| Жидкость ≳1 л | суп, бульон | `thaw_before_day` с запасом; подпись «с вечера» к этому дню |
| Жидкость меньше литра | соус 800 мл | вечер накануне слота |
| Плотный кусок / желе мяса | говядина волокнами | вечер накануне |
| Плоский пакет | котлеты, филе, полоски | вечер накануне |
| Нарезка / противень кубиком, тушёная капуста | овощи, тыква | **утро дня слота** — за несколько часов хватает; с вечера «за компанию» с мясом овощи просто лежат |

Коды нарезки для алгоритма: `roasted_vegetables`, `roasted_pumpkin`, `roasted_veg_*`, `braised_cabbage`. Жидкость — `unit: ml`. Остальное морозное — вечер накануне.

Не подписывать все морозные боксы одного дня одной фразой, если у них разный режим: мясо «с вечера», овощи «утром».

Сырую рыбу понедельника «не морозят» — решение **этого** набора (куплен в вс, слот через сутки), не общая норма хранения рыбы. В шкале вс без дня недели: «эту часть оставляем холодной, слот ближайший».

# 33. Учить логике набора

Будничный шаг не только команда. Если воскресенье специально чего-то не делает — слот объясняет зачем.

Примеры, которые надо писать, а не подразумевать:

- картофель в борщ/суп режем и варим в день еды, чтобы он не стоял несколько дней в готовом супе и не раскис;
- рис варим непосредственно перед едой: так вкуснее, и готовый рис не оставляют надолго при комнатной температуре;
- капусту к курице тушим в пятницу, а не в вс: мокрую капусту на пять дней не кладут.

Это обучение системе, не «ещё один шаг».

# 34. Готовность на карточке слота

Температуры JSON — [SAFETY.md](../SAFETY.md). На тексте для человека:

**Основной ориентир** — вид самой толстой части. **Факультативно** — кухонный термометр. Не выдавать цвет и «прозрачный сок» за санитарную гарантию. Не требовать термометр (его нет у большинства).

| Продукт | Писать | Не писать как гарантию |
|---------|--------|------------------------|
| Фарш птицы | Разломите самую толстую котлету: фарш полностью изменился, сырого нет. Если есть термометр — 74 °C в центре | «корочка румяная» одно; rare |
| Птица полосками | Самая толстая полоска белая насквозь, сырого нет. Если есть термометр — 74 °C в центре | «сок прозрачный» |
| Рыба | Время зависит от толщины; готовое мясо матовое и легко разделяется вилкой. Минуты — ориентир | «12 минут» как обещание любой толщине |
| Яйцо в шакшуке | Белок схватился, желток — как любите. Если нужен полностью безопасный вариант — доведите яйцо до полной готовности | жидкий желток как одинаково допустимый для всех |

# 35. Посуда, руки, честность минут

Ресурсы по умолчанию (§14) дополнить **явным списком в лиде воскресенья**:

> Понадобится: 2 кастрюли, 2 сковороды, 2 противня, 10 контейнеров.

Это влияет на выбор набора. Не прятать трёхконфорочную сессию за «88 мин руками».

В ручные минуты входит: нарезка килограммов, жарка, лепка, мойка доски после рыбы/мяса, раскладка по боксам, водяная баня. Не только «время рецепта».

Если живой человек на обычной кухне уйдёт за заявленные руки на десятки минут — завысить `t_sunday_active_min`. Округлять вниз запрещено. Оптимистичные 72 минуты при десяти боксах и двух противнях — повод пересчитать, не гордость.

Стена может быть длинной из‑за томления мяса. Руки — нет: они не равны «стена минус пассив».

# 36. Одна основа — две разные тарелки

Повтор заготовки (говядина чт/пт, соус вт/сб) — нормальная экономия.

Плохо: «та же заготовка, другая тарелка», если на вкус это один контейнер два дня.

Нужно сменить не только гарнир, но и вкус и подачу: кислота, свежая зелень, другая заправка, другой носитель (капуста vs свежий рис). Человек должен почувствовать две тарелки.

Голое «положи волокна на стол» — провал CONTAINER_TEST.

# 37. Роли на тарелке и в данных

Пока новые поля JSON не заведены, редактор **обязан** классифицировать каждую сущность. Иначе через месяц поедут ккал, аллергены, закупка, порции и замены.

| Роль | Что это | КБЖУ шапки набора | Аллергены набора | Закупка | В слоте |
|------|---------|-------------------|------------------|---------|---------|
| Основное (`primary`) | `PrepSlot.recipe` | да | да | через сырьё / карточку | да |
| Заготовка (`component`) | бокс вс | нет как блюдо | через блюда, которые её едят | сырьё компонента | через `container_ids` |
| Гарнир слота | крупа сейчас или бокс-гарнир | если это primary; крупа «сварить сейчас» — не companion | если в составе primary или всегда в шагах | да, если не шкаф | в `steps` |
| Сопровождение (`companion`) | хлеб, салат, сметана | **нет** (шапка считает основные slug) | да, если всегда на тарелке (хлеб → глютен) | да, если не шкаф | обязательно в `steps` |
| Добавка | «орехи **или** масло» | нет | если ветка выбрана — по канону карточки | по канону | в `steps` |
| Остаток | `reheat` N+1 | как primary источника | как источник | нет новой | шаги разогрева |
| Банка закрытая | закупка | нет | как слот, где откроют | да | открыть в слоте, не бокс холода |

Не писать человеку «ориентир ккал — по slug, не по companion». Это внутренняя модель. На экране — «средний ориентир на блюдо», как [UX-PROPOSAL.md](../UX-PROPOSAL.md).

Кабачок к яйцам «оставьте в контейнере» — остаток **компонента**, не `reheat` блюда и не companion.

# 38. «Без вчерашнего» — цена плана

Переключатель меняет слоты и закупку. Это другой план, не фильтр.

Человеку показать цену, не магию:

> Без вчерашнего: +N быстрых блюд, +M позиций к закупке.

N — число заменённых `reheat`. M — уникальные строки `shopping_add` после слияния. Если два leftover в одном переключателе складывают кабачок/рис — одна строка, не две.

Внутреннее «кабачок/рис могут сложиться» в текст для человека не писать.

# 39. Голос: кухня, не редакция

Канон фраз — [WEEKLY-PREP-TZ.md](../drafts/WEEKLY-PREP-TZ.md) §8.

Можно: «не вчерашнее», «не из бокса», «не разогрев», «рис варите свежим», «банку откройте сейчас».

Нельзя в шагах и лидах, которые видит человек:

- `вс-кастрюля`, `вс-контейнер`, slug, чип, leftover, companion, `feeds_slots`;
- «фасоль из банки, не вс-кастрюля»;
- «это не противень воскресенья»;
- «не “положи волокна на стол”».

Это комментарии редактора. Их место — ANALYSIS, не UI.

# 40. Ценность, которую обещаем

Каркас уже такой: воскресная подготовка + быстрые будни. Его надо сказать в `summary` и не прятать за тремя цифрами шапки.

Минимум в лиде набора:

1. Воскресенье — один раз собираем основу (и сколько это стены / рук).
2. Будни — 10–20 минут у плиты.
3. Что сняли: ежедневная нарезка, поиск «что приготовить», полная готовка с нуля.

Цифры шапки без этого абзаца — арифметика, не ценность.
