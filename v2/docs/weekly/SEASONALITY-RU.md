# 0. Что считать сезонностью

Не использовать бинарное:

```text
сезон / не сезон
```

Нужно различать:
1. естественный местный сезон;
2. хранение урожая прошлого сезона;
3. тепличное производство;
4. импорт;
5. заморозку;
6. сушёные/консервированные формы.

Сезонный продукт вне своего сезона не становится запрещённым. Он просто должен конкурировать с более логичным сезонным вариантом.

# 1. Региональная оговорка

РФ климатически неоднородна. Таблица — федеральная редакционная база, прежде всего для массового городского пользователя и европейской части РФ.

Не писать:

> «в июне это сезонно во всей России».

Предпочтительные формулировки:
- летом;
- конец лета — начало осени;
- поздняя осень и зима;
- хранится с прошлого сезона;
- доступно круглый год.

# 2. Классы сезонности

| Код | Значение |
|---|---|
| `peak` | выраженный сезон |
| `seasonal` | сезонный продукт |
| `stored` | прошлогодний урожай, хорошо хранится |
| `greenhouse` | доступность за счёт тепличного выращивания |
| `imported` | вне российского сезона обычно привозной |
| `frozen` | разумная круглогодичная замена |
| `dried` | сушёная форма |
| `year_round` | практически не зависит от сезона |

# 4. Редакционные правила

## Огурцы и помидоры

Летом — главные кандидаты для свежих сезонных недель.

Зимой не запрещены, но для базовых наборов предпочтительнее:
- капуста;
- морковь;
- свёкла;
- другие корнеплоды;
- замороженные овощи;
- консервированные томатные основы.

## Капуста

Осенью и зимой — один из главных базовых продуктов:
- хорошо хранится;
- подходит для супов;
- подходит для тушения;
- подходит для свежей подачи;
- хорошо сочетается с мясом и бобовыми.

## Грибы

Лисички и белые грибы — сезонный бонус, а не круглогодичная основа.

Шампиньоны и вешенки — круглогодичная база.

Не фиксировать точные месяцы для дикорастущих грибов как общероссийский абсолют: сезон зависит от региона и погоды.

## Роли овощей в неделе

Не проектировать «морковь, лук, помидор» как плоский список. Назначать роль:

| Роль | Примеры | Зима | Лето |
|---|---|---|---|
| База хранения | морковь, лук, капуста, свёкла, картофель | основа рациона | остаётся, но не единственная |
| Сезонная свежесть | огурец, помидор, кабачок, ягоды, свежая зелень | не база; теплица/импорт с объяснением | основа свежих слотов |
| Заморозка | брокколи, цветная капуста, горошек, ягоды | законная замена свежего | дополнение к пику |
| Грибы | шампиньоны, вешенки | круглогодичная база | плюс лесной бонус |

Тогда «Неделя сентября» и «Неделя января» отличаются составом, а не названием.

## Хранение, которое ломает слот

Не зависит от календаря, но ломает сезонную неделю так же, как несезонный огурец.

| Продукт | Правило |
|---|---|
| Помидор на салат | комната, не холодильник; резать в еду (холод убивает летучие, мякоть «ватная») |
| Крестоцветные варёные | не герметика с вс до среды (сероводород); бланш + шок-мороз или слоты Пн–Вт |
| Запечённые овощи | остужать открытыми пластом |
| Кусковой варёный картофель | не морозить |
| Готовая белая рыба | не морозить; не leftover после 48 ч |
| Консервы рыбы и бобовых | `year_round`, открывать в будни |

# 5. Сезонные версии недели

Допустимы:

```text
Неделя июля
Неделя сентября
Неделя января
Неделя апреля
```

Но различие должно быть реальным:
- другой набор овощей;
- другая доля свежих/замороженных;
- другие блюда;
- другое хранение;
- другая воскресная подготовка.

Не менять только название.

# 6. Сезонная замена

Для ключевого сезонного продукта хранить редакционную пару:

```text
product
season
fallback
```

Примеры:

```text
огурец
лето → свежий
зима → не базовый овощ
fallback → капуста / морковь / свёкла

помидор
лето → свежий
зима → томатное пюре / консервированные томаты

кабачок
лето → свежий
зима → замороженный, если блюдо переносит текстуру

ягоды
лето → свежие
зима → замороженные
```

Fallback должен сохранять **питательную и кулинарную роль**, а не обязательно быть идентичным продуктом.

# 7. Свойства для meal prep

Для продукта/группы желательно иметь не один ярлык «сезон», а пачку:

| Поле | Зачем |
|---|---|
| `season` | местный пик / хранение / теплица / импорт / заморозка |
| `storage` | как живёт до готовки: кладовая, холодильник, морозилка |
| `shelf_life` | короткая / средняя / длинная жизнь после покупки |
| `freezable` | да / с потерей качества / нет |
| `prep_ahead` | хорошо / терпимо / плохо готовить в вс |

Примеры пригодности:

| Свойство | Пример |
|---|---|
| `prep_ahead_good` | морковь, капуста |
| `prep_ahead_ok` | брокколи, перец |
| `prep_ahead_poor` | нарезанный огурец, помидор в холодильнике, готовая белая рыба |
| `freeze_good` | ягоды, горошек, сырые рыбные котлеты, бланшированные крестоцветные |
| `freeze_quality_loss` | огурец, салат, кусковой варёный картофель, готовая белая рыба |
| `fresh_finish_required` | зелень, свежий салат, яйца, паста до готовности, филе рыбы |

Сезонность и пригодность к prep — разные характеристики. Огурец летом сезонный и при этом плохой кандидат в вс-нарезку на четверг.
