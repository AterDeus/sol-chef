## Девять претензий (2026-09-05)

1. **«У меня».** Вернуть жест V1: менять количество якоря (основной продукт), сразу пересчёт списка. В V1: ±, поле, **г↔кг**, factor, имя якоря, сброс, hint что таймеры не масштабируются. Счёт по-прежнему только Django (`anchor_weight`).
2. **Cook mode на десктопе.** V2 выглядит как мобильный wizard. Нужен нормальный десктопный режим. Снять с V1: setup (старт сейчас / ко времени), prep «Заранее», таймер ±, обзор всех шагов. На ≥769px **не** прятать список шагов в `<details>`: две колонки (текущий шаг + лента/оглавление). Телефон — пошагово как сейчас, но с обзором. Wake Lock оставить.
3. **Favicon** — тот же `assets/favicon.svg`, что у V1. Копировать в `v2/frontend/public`, корень не трогать.
4. **Вариации — не абзац.** Пример: жаркое из говядины → с грибами / с пармезаном / с кабачками. Основа одна, состав и шаги чуть другие. Переключатель сразу меняет ингредиенты (и шаги, аллергены, заметки варианта). Не второй независимый slug в выдаче как «другое блюдо», если это тот же вкус. Модель (дельты vs семейство slug) — развилка HUMAN; UX должен показать жест на странице.
5. **Заметки.** Не один blob. Квоты контента: минимум 3, в среднем 6, максимум 10 на сложное блюдо. В UI — список карточек/пунктов (заголовок + текст), не простыня. Для среза V1 (43) не выдумывать 6 заметок из воздуха — экран должен жить с 0…10; квоты — в RECIPE.md для волн.
6. **Посуда.** Одно блюдо: кастрюля на плите / духовка / казан — свои нюансы. Переключатель на рецепте (и фильтр в книге/калькуляторе). Не путать с `cook_method` (жарка vs тушение) и не плодить пустые гиды. Коды equipment — VOCAB, HUMAN 2.5 был пуст: аналитик предлагает список для HUMAN.
7. **Книга ≠ калькулятор.** `/recipes` — каталог с иерархией (листать книгу). `/calculator` — «что есть дома» → выдача блюд + **что докупить**. Сейчас оба экрана — одни чипы. Развести вопросы и жесты.
8. **Первый уровень — основа блюда, не кладовка.** Простой режим: говядина + жарить + сковорода → стейки и подобное. Продвинутый: после выбора основы раскрываются отрубы / части / сорт рыбы / конкретные овощи и дополнения (вино, морковь, сельдерей) → например оссобуко (голяшка на кости + вино + морковь + сельдерей) с полным текстом: подготовка мяса, обжарка, бульон vs вода, специи. «Есть дома» — отдельный слой калькулятора (докупить), не первый ряд чипов как сейчас «Есть» = protein_base.
9. **Меню и иконки.** Спрайт V1 (`assets/images/icons.svg`, Lucide stroke 1px, `.cursor/rules/icons.mdc`). В шапке и таббаре — иконки, не голый текст. Добавить недостающие с lucide.dev (stroke 1). Не цветные эмодзи. Не менять корневой спрайт «заодно»; копия в `v2/frontend`.

## Что не оспаривать без причины

- Шапка D+: Калькулятор · Рецепты · Справочник · Советы. URL `/calculator`, `/recipes/<slug>`.
- «У меня» только на рецепте. На калькуляторе другие слова («Есть» / «Без чего» / «Докупить» — уточнить).
- Масштаб и ранг — Django, не React.
- Печать не в этом спринте. Аккаунты не в этом спринте. Волны рецептов без «стартуй волну 1».
- High-risk: блок «Осторожно». `unknown` ≠ «нет».
