# Правила безопасности рецепта (приложение V2)

Версия: `2026-09-11-v3`  
Канон продукта 2.0. Неизвестный статус ≠ безопасность.

Аллергены, температуры и high-risk — детерминированный валидатор + человек на флаги. Калькулятор отсекает и `contains`, и `unknown`.

## Аллергены

Источник правды — **`canonical_id` ингредиента** с жёстким флагом аллергена, не подстрока в сыром тексте.

`contains` — подтверждено **обязательным** составом. `may_contain` — следы, если явно. `unknown` — нельзя заменить на «нет». Строки «для подачи» / «по желанию» в аллергены блюда не входят: йогурт к карри можно не класть — молоко на карточке не висит. Креветки в пасте с креветками обязательны — `crustacean` остаётся. Вариации с дельтой состава обязаны иметь `allergen_delta`.

Рыба, ракообразные и моллюски — **три разные группы** (ТР ТС 022/2011). Креветка ≠ `fish`. Сельдерей (`celery`) в списке 14; часто «невидим» в **магазинном** бульоне без состава → `unknown: celery`. Не вешать на бульон `milk`/`gluten` «на всякий случай»: тушёное мясо с «бульон или вода» из‑за этого врало «неизвестно, есть ли молоко». Строка «бульон или вода» / «вода или бульон» — без unknown (вода в рецепте допустима).

| Код | Примеры канона | Не вешать код |
|-----|----------------|---------------|
| `milk` | коровье молоко, сливки, сыр, сливочное масло, сметана, йогурт, творог | кокосовое/миндальное/овсяное/рисовое молоко; кокосовые сливки; соевое молоко (это `soy`); растительное, оливковое, кокосовое масло, масло какао |
| `gluten` | пшеничная мука, хлеб, пшеничная паста, обычный соевый соус | рисовая, гречневая, миндальная, кукурузная, овсяная (как мука без пшеницы) мука |
| `egg` | яйцо, яичный белок/желток | — |
| `fish` | треска, лосось, судак, минтай | креветки, крабы, мидии, кальмары |
| `crustacean` | креветки, крабы, раки, омары | рыба, мидии |
| `mollusc` | мидии, кальмары, осьминог, устрицы | рыба, креветки |
| `soy` | соя, тофу, соевое молоко, соевый соус | — |
| `tree_nut` | миндаль, грецкий, фундук; миндальное молоко | — |
| `celery` | корень, стебель, лист сельдерея; многие бульоны | — |
| `sesame` / `mustard` / `peanut` / `sulfite` / `lupin` | по канону | — |

ETL среза V1: **сид-словарь** строк ингредиента → `canonical_id` + списки аллергенов (DATA-MODEL). Regex по русским падежам как основной путь **запрещён** (пропуски и ложные `contains`). Нет ключа в сиде — импорт падает, не «ну ладно, без аллергена». Соевое молоко → `soy`, не `milk`. Миндальная мука → `tree_nut`, не `gluten`.

## Температуры

В шаге два поля, оба не масштабируются с порциями:

- `pull_internal_temperature_c` — снятие с огня (может быть на 2–5 °C ниже цели из‑за carryover).
- `target_internal_temperature_c` — безопасный конец, **после отдыха**, если отдых заявлен.
- `hold_seconds` — выдержка (для свинины 63 °C — минимум 180 с).

Валидатор судит по **target** (и hold, если правило требует отдых). Не браковать рецепт, где pull 69 °C, а target 72 °C с отдыхом. Если заполнен только pull без target — ошибка. Оборудование округлять до 5–10 °C; внутренние — не «удобно» вниз.

В JSON V1 полей температур нет: для птицы/свинины/рыбы срез заполняет сид `v1_step_temperatures` (число рецептов — DEFAULTS). Это контент/safety-задача ETL, не «само проставится из notes».

| Продукт | Минимум `target` | Примечание |
|---------|------------------|------------|
| Куриная/индюшиная грудка | 72 °C | Как `meat-poultry.json` |
| Куриное/индюшиное бедро, голень **на кости** | 82 °C | У кости, цельный кусок |
| Куриное бедро **без кости** (полоски, кубики) | 74 °C | Как USDA для птицы; не писать «82 °C у кости», если кости нет |
| Целая птица | 72 °C грудка и 82 °C бедро | Оба в шагах |
| Фарш птицы (котлеты, тефтели) | **74 °C** | Rare запрещён |
| Рыба готовая (не sashimi, не промышленные консервы в холодной сборке) | 63 °C | Иначе `raw_fish`. Консервы в `no_cook` боуле повторно не греть и `target` не ставить |
| Фарш говядины/свинины/баранины (котлеты, бургеры, тефтели, фарш в лазанье) | **71 °C** | Rare / medium-rare **запрещены**: бактерии по всему объёму |
| Свинина, цельный отруб | **63 °C + отдых ≥ 3 мин** **или** 71 °C | Не 50–55 °C |
| Говядина/баранина стейком | по рецепту | Rare допустим только для цельного куска, не фарша |

## High-risk

В каталог **можно** после дополнительной модерации человеком. На странице рецепта обязателен заметный блок **«Осторожно»** (или «Внимание»): зачем флаг, кого не касается (дети, беременные — по смыслу), что проверить. Без блока — не публиковать. Детские и «диетические безопасные» подборки такие рецепты не показывают.

Флаги: `raw_egg`, `raw_meat`, `raw_fish`, `raw_milk`, `wild_mushrooms`, `ground_meat`, `preservation`, `fermentation`, `child_food`, `fire_hazard`, `poultry_temp`.

| Триггер | Правило |
|---------|---------|
| Сырые яйца в готовом блюде | `raw_egg`; не в детские подборки |
| Тартар, карпаччо, строганина, севиче, суши/сашими | `raw_meat` и/или `raw_fish`; предупреждение в тексте; запрет детских/диетических подборок; для рыбы — требование промышленной проморозки в тексте |
| Сырое непастеризованное молоко без кипячения | `raw_milk` (листериоз) |
| Грибы | whitelist культивируемых: **шампиньоны, вешенки, шиитаке, эринги**. Любые другие (белые, лисички, опята, «лесные», сушёные смеси) → `wild_mushrooms`, ручной аудит источника |
| Консервация, ферментация, сушка мяса/рыбы дома | как раньше |
| Детское питание | `child_food` |
| Пожар (щепа в бытовой духовке, открытый огонь в квартире) | `fire_hazard` |
| Копирование чужого текста/фото | Можно только с именем источника и ссылкой; человек проверяет, что рецепт реальный. Без атрибуции — Critical. На сайте — как связаться, чтобы убрали |

`cook_method: no_cook` при белке мясо/рыба/птица без флага raw_* — ошибка валидатора, **кроме** холодной сборки **промышленно готового** белка: консервы тунца/горбуши; копчёная курица, ветчина, тушёнка и прочая готовая мясная нарезка из магазина. Это не тартар и не повторная варка до `target`. Тартар / сырое филе — флаг `raw_*` и температура или запрет, как в таблице выше.

## Охлаждение, полуготовность, разморозка, сроки

Для leftover и слоя «На неделю». Слоты, деление боксов и голос набора — [WEEKLY-PREP-DESIGN.md](weekly/WEEKLY-PREP-DESIGN.md) §28–34. Здесь — числа и запреты.

**Крупы (рис, гречка и др.).** Споры *Bacillus cereus* переживают варку. Если кастрюля остывает 3–4 часа на плите, токсин может накопиться и **не разрушается** повторным кипячением. Рассыпать тонким слоем, чтобы крупа быстро перестала быть горячей, и убрать в холодильник как можно скорее; не оставлять остывать на столе надолго. Для скоропортящихся готовых продуктов ориентир — не дольше **двух часов** при комнатной температуре. Минуты «60–90» не дублировать в каждом рецепте. В наборе рис к боулу варить в слот, не вс-кастрюлей на неделю.

**Горячий объём → холод / мороз.** Два запрета сразу: не оставлять большую кастрюлю часами при комнатной температуре **и** не ставить большой кипяток или очень горячую еду сразу в холодильник или морозилку. Переложить в неглубокую ёмкость или плоский слой либо поставить в холодную водяную баню, затем убрать в место хранения, не оставляя надолго на кухне. В морозилку — только после этого. Критерий — протокол охлаждения, не «перестало парить». «Снимите и сразу в морозилку» для бульона ~1 л, соуса или томлёного мяса — брак.

**Полуготовность.** Обжаренное снаружи куриное филе — не готовая еда. Считать сырым: отдельно от готового и зелени; в шагах слота явно довести до `target` таблицы выше (бедро без кости / полоски — 74 °C). Подпись вроде «можно есть из контейнера» запрещена.

**На карточке, не вместо JSON.** Домашний признак — самая толстая часть (фарш изменился, полоска белая насквозь, рыба матовая и слоится). Если есть термометр — `target` из таблицы. Цвет, корочка и «прозрачный сок» не писать как санитарную гарантию. Термометр не требовать. Жидкий желток не объявлять безопасным: «как любите» можно, рядом — полностью сваренный вариант.

**Разморозка.** Не один шаблон «с вечера». Около 1 л жидкости в холодильнике при ~+4 °C: **24–36 часов** (`thaw_before_day` с запасом). Плотный кусок мяса и плоский пакет котлет/филе — вечер накануне слота. Нарезанные запечённые овощи и тушёная капуста оттаивают за несколько часов: утро дня слота, не с вечера вместе с мясом. Подпись на сетке считает алгоритм из типа и размера бокса.

**Фасовка горячего.** Запечённые овощи и каши закрывать крышкой только после остывания пластом. Иначе конденсат возвращается в продукт.

**Сроки холодильника (редакционный ориентир, не ГОСТ).** Готовые блюда и остатки — **3 суток** по умолчанию, не 4–6. После оттайки часы заново; срок — у **этой** смеси, не общий «противень 3 суток» (грибы на противне короче, чем тыква с морковью). Сырая рыба — 1–2 суток; «не морозить до понедельника» — решение конкретного набора, не общая норма. Открытые рыбные и бобовые консервы — 3–4 суток в холоде, не в железной банке. Закрытая магазинная банка — кладовая по условиям производителя, не «неделя в холодильнике до открытия». Всё, что нужно позже холодильного окна, проектировать через морозилку. Подробная таблица для наборов — DESIGN §29.

Температуры разогрева leftover — те же `target`, не «тёплое».

## Масштабирование

Температуры, pull/target, hold и таймеры шагов **не** масштабируются.

Не вводить второе поле `scalable_rule`. То же самое — enum `scale_mode` + bool `scalable` (VOCAB). Слова `fixed` в enum нет:

| Запрос | Поле |
|--------|------|
| `linear` | `scale_mode: linear` |
| `manual` | `scale_mode: manual` — не авто-масштаб; в UI «проверьте по исходному рецепту» |
| `fixed` | **`scalable: false`** (scale_mode у строки не важен) |

Соль/специи «по вкусу»: `unit: to_taste`, `scalable: false`.

**Выпечка / химия:** разрыхлитель, дрожжи, желатин — не `linear` (избыток даёт горечь или резину). По умолчанию `manual`. Сода в бархате/маринаде — пропорция к мясу, `linear`. Не путать с V1-автодетектом «сода → gentle».

**Сковорода:** при `cook_method: pan_fry` в шаге жарки стейков/отбивных/котлет обязана оговорка: обжаривать порциями, не перегружать сковороду (иначе тушение в соку). Температуры жарки от этого не масштабируются.
